# Tugas Akhir Mata Kuliah Pemrograman Berbasis Web

## Deskripsi Proyek
Proyek ini merupakan tugas akhir untuk mata kuliah **Pemrograman Berbasis Web**.  
Aplikasi yang dibuat adalah **Website Pengelolaan Buku** menggunakan framework **CodeIgniter 4**.

## Teknologi yang Digunakan
- PHP
- CodeIgniter 4
- MySQL
- HTML, CSS, JavaScript

## Fitur
- Menampilkan daftar buku
- Menambahkan data buku
- Mengedit data buku
- Menghapus data buku

Aplikasi ini mengimplementasikan konsep **CRUD (Create, Read, Update, Delete)** untuk mengelola data buku.
